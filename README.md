# NovaMart Intelligence Dashboard

A fully-static analytics dashboard for NovaMart.  
All computation is done **once, locally** via `export_data.py`; the result is a single precomputed JSON file that the browser loads directly — no backend, no Python runtime, fully Vercel-compatible.

---

## Stack

| Layer | Technology |
|---|---|
| Data export (local) | Python 3.10+ · papermill · pandas · sklearn · statsmodels |
| Frontend | Single HTML file · pure CSS · vanilla JS |
| Hosting | Vercel (static) — zero server-side code |

---

## Project Structure

```
novamart_dashboard/
├── export_data.py       # Run once locally: executes notebook → writes static/data/analytics.json
├── executor.py          # Notebook runner + Colab-cell patcher  (used by export_data.py)
├── extractor.py         # Parses cell outputs into structured JSON (used by export_data.py)
├── vercel.json          # Vercel static deployment config
├── requirements.txt     # Python deps (local export only)
├── static/
│   ├── dashboard.html   # Single-file frontend — loads ./data/analytics.json via fetch()
│   └── data/
│       └── analytics.json  # ← generated by export_data.py; commit this file to deploy
```

> `main.py` (the old FastAPI server) is kept for reference but is no longer needed.

## Workflow

### 1 — Generate the data file (once, locally)

```bash
# Install dependencies (local only, never runs on Vercel)
pip install -r requirements.txt

# Execute the notebook and export all analytics to static/data/analytics.json
python export_data.py "NovaMart_v3 (1).ipynb" Project_2.xlsx
```

The script patches out Google Colab upload cells automatically, executes the notebook via papermill, extracts every analytics section, sanitises NaN/Inf → null, and writes:

```
static/data/analytics.json   ← all precomputed outputs
```

### 2 — Preview locally (optional)

```bash
# Any static file server works, e.g.:
python -m http.server 8000 --directory static
# then open http://localhost:8000/dashboard.html
```

### 3 — Deploy to Vercel

```bash
# Commit the generated data file
git add static/data/analytics.json
git commit -m "chore: update precomputed analytics data"
git push

# Vercel picks up the push automatically (outputDirectory = "static" per vercel.json)
```

## How the Frontend Works

On page load `dashboard.html` calls:

```js
fetch('./data/analytics.json')
  .then(data => renderDashboard(data))
```

All rendering is pure client-side JS — KPIs, channel tables, segment cards, campaign clusters, discount analysis, lead/repeat-buyer models, and the Pareto banner with count-up animations.

If `analytics.json` is missing or fails to load, the page shows a clear error message with the exact `export_data.py` command to run.

---

## Re-running After Data Updates

Whenever the source notebook or Excel file changes, simply re-run `export_data.py` and redeploy.  The Vercel build has zero compute cost — it just serves the static files.

---

## Error Handling

- If a notebook section is missing from the output, that dashboard card shows *"Data unavailable"* without crashing.
- Extraction warnings are surfaced in an **Extraction Notes** panel at the bottom of the dashboard.
